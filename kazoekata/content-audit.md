## 唯一解性の確認方法

正解の助数詞以外にも正しい用法がある題材では、別の正しい語を誤答に使わない方針です。「一般的」「伝統的」と書くだけで別用法を誤りにしません。

| 確認した点 | 例 |
|---|---|
| 数える対象を限定 | 電車は運行本数ではなく車両。電話は機器ではなくかかってきた回数 |
| 状態を限定 | 未記入のはがき、プリントした写真、切る前の食パン、さやから出した豆 |
| 一組と片方を区別 | くつ・手袋・くつ下・鐙・狛犬・屏風 |
| 商品と生き物を区別 | イカ・カニは魚屋で扱う丸ごとの商品。匹も誤りとは説明しない |
| まとめた量を限定 | ブドウ・バナナの房、海苔10枚の帖、粉薬の一包 |
| 特殊な用法を明記 | 文化財資料での鞍・笈・銅鏡・銅鐸など |
| 同音の誤答を除去 | ほうれん草の把＝わと、鳥の羽＝わを同じ4択には置かない |
| 歴史用法を誤答にしない | 毬に「足」を使う記載があるため、低学年の個の問題の誤答から足を外す |

「家＝軒」と「建物＝棟」、「本」と「絵本」、「証明書」と「領収書」など、関連するが別の題材・視点は残しています。これは、ユーザーの低学年候補に本・絵本・辞書などが別題材として含まれている方針に合わせています。同じ題材の言い換え・同じ対象の別状態だけで問数を水増しすることは避けました。

## 読み・説明の修正

- 背：今回の日本目録規則の付表では「せ」。鞍・笈を「はい」と読む初稿を修正。
- 頭：動物の「とう」と、兜・烏帽子の「かしら」を別の助数詞IDで管理。
- 口：文化財資料にある「こう／く」を保持。鐘の解説では「いっこう」を示す。
- 張：選択肢は「はり」で統一し、該当する解説で「ちょう」の読みも補足。
- 挺：銃・乗り物・そろばんでは「ちょう」であり、「てい」と読ませない。
- 貫：にぎりずしの1貫が指す個数・語源を一律に断定しない。
- 箏：「琴」一般の数量表だけに頼らず、大阪三曲協会の箏＝面の説明で確認。
- 問題文に「いっぽん、にほん」などの答えを先に示す初稿を修正。例数は回答後の解説に置く。

## 機械点検と編集監査の区別

機械点検では、200問・各50問・ID重複なし・題材キー重複なし・各4択・正解キー整合・既知の別解が誤答に入っていないこと・同じ読みの選択肢がないこと・読めない漢字が問題文や解説に残っていないことを確認しました。

唯一解性と意味上の題材重複は、問題文・選択肢・条件・根拠を照らした編集監査です。自動チェックだけで言語上の正誤を証明したものではありません。

個別題材の用例を直接確認した問題が154問、一般用法を確認して題材に適用した問題が46問です。マニアック編は50問すべて直接用例確認です。一般用法への適用を「辞典の個別項目を閲覧済み」とは表示しません。

難易度は題材の身近さと数え方の専門性で確認しています。低学年は基本助数詞の練習、高学年は知っておきたい語、大人は社会生活や食品の用法、マニアックは伝統的な道具・文化財の用法を中心にしました。実際の正答率・遊びやすさは、実装後のプレイ評価が必要です。
